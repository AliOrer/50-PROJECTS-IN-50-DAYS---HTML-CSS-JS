# StarterApp

HTML, CSS ve Vanilla JavaScript ile oluşturulmuş; hafif, duyarlı (responsive) ve geliştirilmeye açık temel web başlangıç şablonu.

## Özellikler

- **Sıfır Bağımlılık:** Ek bir kütüphane veya framework gerektirmeden saf HTML5, CSS3 ve ES6+ JavaScript ile çalışır.
- **Açık / Koyu Tema Desteği:** CSS değişkenleri (`:root`) kullanılarak tek tıkla tema geçişi sağlar.
- **Responsive Tasarım:** Masaüstü ve mobil ekran boyutlarına otomatik uyum sağlar.
- **Etkileşimli DOM Yapısı:** Canlı durum bildirimi ve sayaç bileşeni içerir.
